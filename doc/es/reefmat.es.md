# ReefMat:
- Interruptor de avance automático (activar/desactivar)
- Avance programado
- Valor de avance personalizado: permite seleccionar el valor de avance del rollo
- Avance manual
- Cambiar el rollo.
>[!TIP]
> Para un rollo nuevo completo, ajuste "Diámetro del rollo" al mínimo (4,0 cm). El tamaño se ajustará según su versión de RSMAT. Para un rollo parcialmente usado, introduzca el valor en cm.
- Dos parámetros ocultos: modelo y posición, si necesita reconfigurar su RSMAT
