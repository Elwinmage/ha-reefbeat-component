# ReefMat:
- Interruptor de avanço automático (ativar/desativar)
- Avanço programado
- Valor de avanço personalizado: permite selecionar o valor de avanço do rolo
- Avanço manual
- Trocar o rolo.
>[!TIP]
> Para um rolo novo completo, defina "Diâmetro do rolo" para o mínimo (4,0 cm). O tamanho será ajustado conforme a sua versão do RSMAT. Para um rolo parcialmente usado, introduza o valor em cm.
- Dois parâmetros ocultos: modelo e posição, se precisar de reconfigurar o seu RSMAT
